Modeling self-assembly at the cellular scale

Particle-based simulations investigate how interactions between cellular components can produce organized, sarcomere-like patterns.

ESPResSo repository ↗

The question

How can interactions between myosin, Z-disc components, and actin drive organized structures, and which parameters control that organization?

My contribution

  • Extended the open-source C++ molecular dynamics package ESPResSo by implementing custom interactions.
  • Developed and explored particle-based models in two and three dimensions.
  • Ran parameter sweeps and analyzed stochastic simulation outputs with Python.
  • Built quantitative analyses of recruitment, periodicity, coherence, and fluorescence recovery after photobleaching (FRAP).

What the work delivers

The project connects interaction-level model design to quantitative measures of organization and particle exchange. Analysis includes spatial order parameters and simulation-based FRAP recovery curves.

This work demonstrates the ability to extend a scientific codebase, implement model physics, organize computational experiments, and build interpretable analysis workflows.
